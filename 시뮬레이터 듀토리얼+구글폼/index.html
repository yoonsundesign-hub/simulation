❓ 각인 시뮬레이터 사용 가이드
1
전면부 문구 입력 영역
이름·직분, 짧은 헌사, 날짜, 전달하는 이를 입력하는 공간입니다.
왼쪽에서 입력한 내용은 우측 전면 패 미리보기에 바로 반영됩니다.
2
후면부 문구 입력 영역
긴 본문을 작성하는 구역입니다. “후면 샘플 넣기” 버튼을 눌러 기본 예시 문구를 불러온 뒤, 상황에 맞게 수정해서 사용할 수 있습니다.
3
문구 컨트롤 패널
폰트 크기(1~3), 행간 너비(1~3), 정렬 위치(위·가운데·아래)를 조절해 실제 각인 느낌을 맞출 수 있습니다. 버튼을 바꿔가며 적정 조합을 찾아보세요.
4
적정 분량 가이드
전체 글자 수와 사용 중인 줄 수를 보여줍니다. 막대가 가득 차거나 빨간색 경고가 뜨면 문장이 기준 영역을 초과했다는 뜻입니다. 글자 수를 줄이거나 행간·폰트 크기를 조절해 주세요.
5
우측 실시간 패 미리보기
왼쪽에서 입력한 전면·후면 문구가 실제 패 비율에 맞춰 실시간으로 표시됩니다. 아래의 58mm · 230mm 표기는 실제 사이즈를 의미합니다.
6
출력 / 저장
A4 PDF 출력 버튼을 누르면 실제 각인 패와 1:1 비율로 A4에 출력해 확인할 수 있습니다.
JPG 이미지 저장은 현재 미리보기를 이미지로 저장해 디자이너·고객과 공유할 때 유용합니다.
💡 TIP

처음 쓸 때 이렇게 시작해 보세요

1) 전면부에서 전면 샘플 넣기를 눌러 기본 형식을 확인합니다.

2) 후면부에서 후면 샘플 넣기로 분량 감을 먼저 잡은 뒤, 실제 내용을 덮어씁니다.

3) 문구 컨트롤 패널에서 폰트·행간·정렬을 바꿔보면서, 적정 분량 가이드가 초과되지 않는 조합을 찾습니다.

4) 마지막으로 우측 미리보기를 확인한 후, PDF 또는 JPG로 저장해 실제 제작에 참고합니다.

언제든 오른쪽 상단 “사용법 보기” 버튼을 다시 눌러 이 안내를 열 수 있습니다.
